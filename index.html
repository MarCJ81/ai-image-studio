    이미지 1장당 비용은 공급자 가격표에 따릅니다. 앱은 결제를 대신하지 않습니다.

    사진 누끼가 잘 안 될 때

    배경이 남아 있어요

    허용 오차를 5~10씩 올리고, 방식은 가장자리 색 자동을 먼저 시도하세요. 배경과 비슷한 색이 피사체 안에 많다면 배경과 연결된 영역만이 안전합니다.

    피사체 가장자리가 하얗게 파여요

    페더를 4~6으로 올리고 강도를 35~45로 낮추세요. 허용 오차가 너무 높으면 피사체가 함께 지워집니다.

    흰 배경 제품 사진이에요

    밝은 배경 지우기가 가장 빠릅니다. 제품에 흰 부분이 많다면 배경과 연결된 영역만으로 바꾸세요.

    누끼 이미지는 어디에 저장되나요?

    메모리에만 있습니다. 새로고침하면 사라지고, 서버로 전송되지 않습니다.

    안전하게 쓰는 법

    • API 키는 sessionStorage에만 저장됩니다. 공용 PC에서는 탭을 닫으면 사라집니다.
    • 키가 필요 없는 작업은 키를 넣지 않아도 전부 됩니다.
    • 이 앱에는 서버가 없습니다. 이미지와 문구는 이 브라우저에서만 처리됩니다.
    • 사람 얼굴이 포함된 사진을 외부 AI에 올릴 때는 초상권·초상 사용 범위를 확인하세요.
    • AI로 만든 이미지를 상업적으로 쓸 때는 각 공급자의 약관을 확인하세요.
