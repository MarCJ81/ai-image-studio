# 원탭 이미지·썸네일 스튜디오

사진 한 장을 넣으면 **배경을 투명하게 지우고**, 유튜브·인스타·스마트스토어·블로그 규격에 맞는 **썸네일 PNG/JPG/WebP**를 브라우저 안에서 바로 만들어 주는 정적 웹앱입니다.

> API 키도, 서버도, 회원가입도 없이 무료 모드가 100% 동작합니다.
> 유료 키(OpenAI · Gemini)를 붙이면 제목만으로 배경 이미지를 생성해 캔버스에 바로 얹습니다.

- 주소(배포 시): `https://marcj81.github.io/ai-image-studio/`
- 빌드 없음 · 의존성 없음 · 외부 요청 없음(무료 모드 기준)

```bash
# 로컬에서 바로 열기 (폰트·캔버스가 file://에서 막히는 브라우저가 있어 HTTP 권장)
cd apps/ai-image-studio
python3 -m http.server 8080
# → http://localhost:8080
```

## 1. 30초 사용법

1. **비율**을 고릅니다. (유튜브 16:9 / 인스타·스레드 4:5 / 정사각 / 스마트스토어 1000×1000 / 블로그 1200×800)
2. **테마**를 고릅니다. (에디토리얼 · 매거진 · 네온 · 미니멀 · 커머스 · 비비드)
3. **사진**을 끌어다 놓습니다. (또는 `Ctrl+V`로 붙여넣기)
4. 필요하면 **배경 투명화** 강도·허용 오차·페더를 조절합니다.
5. **제목**을 씁니다. `**핵심어**`는 포인트색으로 바뀝니다.
6. **PNG 저장**을 누릅니다.

파일명은 제목에서 자동으로 만들어집니다. (`겨울-가습기-3만원대-유튜브.png`)

### 배경 투명화는 어떻게 동작하나

AI 세그멘테이션 모델을 쓰지 않습니다. 브라우저 캔버스에서 **테두리 픽셀의 대표색을 뽑고**, 각 픽셀이 그 색에서 얼마나 떨어졌는지로 알파를 계산합니다.

1. 테두리 고리(2.5%)를 12단계로 양자화해 상위 색 3개를 뽑습니다.
2. `거리 = sqrt((2Δr² + 4Δg² + 3Δb²) / 9)` — 사람 눈에 민감한 초록에 가중치.
3. 임계값 사이는 smoothstep으로 부드럽게. **강도**는 임계값을, **허용 오차**는 폭을, **페더**는 알파 블러 반경을 조절합니다.
4. 기본값 `가장자리 연결`은 테두리에서 시작하는 플러드필이라, **제품 안의 흰 라벨**처럼 배경과 색이 비슷하지만 안쪽에 있는 영역을 지키는 데 강합니다.
5. `밝은 배경 지우기`도 같은 연결 방식을 쓰고, 어두운(색이 있는) 픽셀은 지우지 않도록 보호합니다.

> 사진 누끼는 AI 세그멘테이션이 아닙니다. 피사체와 배경의 색이 뚜렷할수록 잘 되고, 복잡한 배경은 수동 보정이 필요합니다.

**잘 되는 사진**: 단색 배경 제품컷, 스튜디오 촬영, 흰 배경 누끼, 하늘 배경 인물.
**어려운 사진**: 복잡한 실내 배경, 배경과 옷 색이 같은 인물. 이때는 허용 오차를 낮추고 `배경과 연결된 영역만`을 쓰거나, 외부 누끼 도구로 만든 PNG를 넣는 편이 빠릅니다.

## 3. Pro 모드 (내 키로 AI 배경 생성)

`Pro AI 이미지` 탭의 제공자 카드는 **대표 API 3개 + 자체 서버** 순서입니다.

| # | 제공자 | 모델 | 하는 일 | 비용(공급자 가격표 기준, 추정) |
| --- | --- | --- | --- | --- |
| 1 | OpenAI | `gpt-image-1`, `dall-e-3` | 실사·제품 배경 생성 | 약 $0.02~0.08/장 |
| 2 | Google Gemini | `imagen-3.0-generate-002`, `gemini-2.5-flash-image` | 실사 배경 생성 | 약 $0.03~0.04/장 |
| 3 | Anthropic Claude | `claude-sonnet-4-5`, `claude-haiku-4-5` | **이미지 생성 미지원** · 프롬프트 고도화 | 약 $0.003~0.01/회 |
| 4 | 자체 API 서버 | 내 프록시/사내 모델 | CORS 우회, 자체 모델 연결 | 서버 정책 |

- 키는 입력한 탭의 **sessionStorage**에만 남습니다. 탭을 닫으면 사라집니다.
- `생성`을 누르면 프롬프트를 만들어 해당 공급자에게 **브라우저에서 직접** 요청하고, 응답 이미지를 캔버스 배경에 자동 삽입합니다.
- Claude는 이미지를 그리지 않으므로 **프롬프트를 다듬어** 돌려줍니다. 복사해서 ChatGPT·Gemini·Midjourney에 붙이면 됩니다.
- `키 없이 샘플로 체험`은 네트워크를 쓰지 않고 절차형 샘플 배경을 만들어 전체 흐름을 보여 줍니다.

### 브라우저 직접 호출(CORS) 주의

OpenAI는 브라우저에서의 직접 호출을 막는 경우가 있습니다(응답에 CORS 헤더 없음). 이때는 4번 **자체 API 서버**에 프록시를 두세요. Gemini는 대체로 직접 호출이 됩니다.

프록시 계약(예):

```json
POST https://my-proxy.example.com/generate
{ "prompt": "...", "aspect": "16:9", "size": "1536x1024" }

200 OK
{ "data": [ { "b64_json": "iVBORw0KGgo..." } ] }
```

앱의 `응답 이미지 경로`에 `data.0.b64_json`을 넣으면 그대로 읽습니다. `url`을 주면 `{"data":[{"url":"https://..."}]}` + 경로 `data.0.url`도 됩니다.

> 키를 프록시 서버에 두는 구성이 가장 안전합니다. 정적 앱에 키를 넣는 방식은 본인 기기에서만 쓰세요.

## 4. 프롬프트 브리지 (구독 AI 활용)

이미 ChatGPT Plus · Gemini Advanced · Midjourney를 쓰고 있다면 Pro 키 없이도 AI 배경을 만들 수 있습니다.

1. `프롬프트 브리지` 탭에서 도구를 고르고 **프롬프트 복사**.
2. 구독 AI에 붙여넣고 이미지를 받습니다.
3. 받은 이미지를 **2번 칸에 끌어다 놓으면** 배경으로 깔리고 한글 제목이 위에 얹힙니다.

프롬프트에는 항상 `no text, letters, logos, watermark`가 포함됩니다. 글자는 캔버스에서 또렷하게 얹는 쪽이 결과가 좋기 때문입니다.

## 5. 파일 구조

```
ai-image-studio/
├── index.html                 화면 골격 (탭 4개)
├── tokens.css                 C안 Dark Glass 토큰 (캔버스·글래스·보라/민트·불투명 폴백)
├── styles.css                 다크 글래스 스튜디오 · 캔버스 중심 3열 · 모바일
├── app.js                     캔버스 렌더 · 사진 누끼 · Pro 호출 · 브리지
├── core.js                    DOM 없는 순수 로직 (비율·테마·누끼·텍스트·프롬프트·API)
├── engines/
│   ├── design-ref-engine.js   디자인 레퍼런스 v2 (테마 팔레트 검증)
│   └── copy-psych-engine.js   카피심리 8트리거 (제목 후킹 점수)
├── assets/fonts/              IBM Plex Sans KR woff2 3종 (로컬)
├── favicon.svg · privacy.html · robots.txt · sitemap.xml · .nojekyll
├── test.js                    core 단위 테스트 (node)
└── uitest.py                  실제 Chrome 검증 (Playwright)
```

- `core.js`는 `window.ImageStudioCore`와 `module.exports`를 동시에 지원합니다. 브라우저·node에서 같은 코드로 테스트합니다.
- 테마 팔레트는 `design-ref-engine`의 `tokens()`에서 가져와 WCAG 대비를 유지합니다. 엔진이 없으면 내장 팔레트로 동작합니다.
- 제목 후킹 점수는 `copy-psych-engine`의 `diagnose()`를 사용합니다.

### 화면 디자인 (C안 · Dark Glass Studio)

- 캔버스 `#06070B` + 라디얼 글로우 2개(보라·민트). 유리 카드는 `rgba(255,255,255,.05)` + 1px 반투명 보더, blur 18px.
- 포인트는 역할을 고정합니다 — **보라 `#8B5CF6` = 지금 눌러야 할 것(액션·선택·상태)**, **민트 `#34E0C8` = 성공·수치(라이브 점·단계 완료·`01` 인덱스)**. 두 색이 경쟁하지 않습니다.
- 썸네일 작업영역이 화면의 주인공입니다. 스테이지는 세로를 뷰포트에 맞추고, 캔버스는 어두운 체크보드 판 위에 흰 종이로 떠 보이게 뒀습니다(모서리 크롭 마크 · 종이 그림자).
- 패널은 `01 비율 → 05 문구`의 작업 순서를 그대로 번호로 드러냈습니다. 좌우 패널은 내부 스크롤 + sticky, 무대는 순서상 맨 위(모바일)로.
- `prefers-reduced-transparency`에서는 유리 대신 불투명 `#14151B`로 떨어집니다. 라이트 모드는 선택 옵션(상단 해/달 버튼)이며 같은 토큰만 덮어씁니다.

## 6. 개인정보·보안

- **서버 없음.** 사진과 문구는 브라우저 메모리에서만 처리됩니다. 업로드 API가 없습니다.
- **무료 모드 외부 요청 0.** 폰트·이미지·스크립트 모두 로컬입니다.
- **키는 sessionStorage.** `localStorage`에 API 키를 쓰지 않습니다. `키 지우기` 버튼으로 즉시 삭제.
- **키 전송 대상은 사용자가 고른 공급자뿐.** 앱 운영자에게는 아무것도 가지 않습니다.
- 민감정보(이름·연락처·비공개 사업명)와 실제 키 패턴이 저장소에 없도록 테스트가 검사합니다.

## 9. 알려진 한계

- 배경 투명화는 **색 기반**입니다. 의미 기반 AI 누끼가 아니므로 복잡한 배경에서는 수동 보정이 필요합니다.
- 사진은 최대 1500px로 줄여 처리하고, 누끼 후 투명 여백을 잘라 피사체를 키웁니다. 원본 해상도는 보존하지 않습니다.
- OpenAI 직접 호출은 CORS로 막힐 수 있습니다 → 자체 서버(4번) 사용. 커스텀 서버가 이미지 URL만 돌려줄 때도 그 도메인의 CORS 허용이 필요합니다(b64 권장).
- Gemini Imagen의 인물 생성 정책, 각 공급자의 이미지 사용 약관은 앱이 통제하지 않습니다.
- 브라우저가 `toBlob('image/webp')`를 지원하지 않으면 PNG로 대체될 수 있습니다(Chrome 기준 정상).
- 생성 결과와 입력 상태는 새로고침 시 사라집니다(의도된 프라이버시 기본값). 설정만 세션에 남습니다.
