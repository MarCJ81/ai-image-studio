원탭 이미지·썸네일 스튜디오

개인정보 처리방침

시행일 2026-11-22 · 버전 1.1

한 줄 요약

이 앱은 서버가 없습니다. 사진과 문구는 사용자의 브라우저 안에서만 처리되고, 어떤 이미지도 운영자에게 전송되지 않습니다. 유료 AI 기능을 켤 때만 사용자의 키로 해당 AI 회사에 직접 요청합니다.

1. 처리하는 정보와 목적

  • 사진·이미지 파일 — 썸네일 합성과 배경 투명화를 위해 브라우저 메모리에서만 읽습니다. 저장·전송하지 않으며 새로고침하면 사라집니다.
  • 레퍼런스 이미지(선택) — 업로드·붙여넣기한 이미지의 픽셀에서 색·밝기·배치만 계산합니다. 이미지 자체나 추출값을 운영자에게 보내지 않습니다.
  • 제목·부제·배지 등 입력 문구 — 캔버스에 그리는 데만 사용합니다. 역시 브라우저 안에서만 존재합니다.
  • 작업 설정 — 비율·테마·슬라이더 값은 sessionStorage에 저장되어 같은 탭에서 새로고침해도 유지됩니다. 탭을 닫으면 삭제됩니다.
  • API 키(선택) — 사용자가 직접 입력한 경우에만 sessionStorage에 보관하며, 이미지 생성 요청 시 해당 공급자(OpenAI·Google·Anthropic 또는 사용자가 지정한 서버)로만 전송됩니다.
  • 화면 표시 설정 — 라이트/다크 선택만 localStorage에 저장합니다.

2. 전송되는 곳

  • 무료 모드 — 외부 전송이 전혀 없습니다. 사진 누끼, 테마 20종, 다운로드 모두 오프라인 캔버스로 동작합니다.
  • 레퍼런스 벤치마킹 — 유튜브 링크를 넣으면 썸네일 파일을 i.ytimg.com에서 받아와 브라우저 안에서만 색·구조를 분석합니다. 붙여넣기·업로드한 레퍼런스 이미지는 전송되지 않습니다. ‘내 브랜드 프리셋’은 색·구조·작은 미리보기만 이 브라우저의 localStorage에 저장되고, 다른 곳으로 보내지 않습니다.
  • Pro 모드 — 사용자가 ‘생성’ 버튼을 누를 때만, 사용자가 고른 공급자의 API로 프롬프트와 키가 직접 전송됩니다. 이때 해당 공급자의 약관·개인정보 처리방침이 함께 적용됩니다.
  • 무료 AI 프롬프트 다듬기 — 무료 모드에서 ‘무료 AI로 프롬프트 다듬기’를 누를 때만 제목·주제·스타일·현재 프롬프트가 전송됩니다. 무료 체험은 Cloudflare Workers로 운영하는 무료 체험 서버를 거쳐 외부 AI 제공자(Cloudflare Workers AI, 필요하면 Google Gemini·Groq)로 전송됩니다. 서버는 프롬프트와 응답 본문을 저장하지 않고, 방문자 구분용 해시값과 그날의 사용 횟수만 남깁니다(7일 뒤 삭제). 하루 무료 횟수는 브라우저당 5회이며, 다 쓰면 안내와 함께 내 키 연결로 넘깁니다. 사진은 전송되지 않습니다.
  • AI 누끼(인물·사물) — 인식 엔진(MediaPipe)과 모델 파일을 이 사이트에서 한 번 받아 브라우저 안에서만 실행합니다. 사진은 어떤 경우에도 외부로 나가지 않습니다.
  • 광고·분석 — 없습니다. 추적 스크립트, 쿠키, 외부 폰트 CDN을 사용하지 않습니다.

3. 보관과 파기

앱은 별도 보관소를 운영하지 않습니다. 브라우저 저장값은 사용자가 탭을 닫거나 ‘키 지우기’를 누르면 사라집니다. 다운로드한 이미지 파일은 사용자의 기기에 남으며, 그 관리 책임은 사용자에게 있습니다.

4. 사용자의 선택

  • 사진을 넣지 않고도 모든 테마를 사용할 수 있습니다.
  • Pro 기능은 키를 넣지 않으면 작동하지 않으며, 언제든 ‘키 지우기’로 제거할 수 있습니다.
  • 브라우저의 사이트 데이터 삭제 기능으로 저장된 설정을 즉시 지울 수 있습니다.

5. 이미지 권리

사용자가 넣은 사진의 저작권·초상권은 사용자에게 있습니다. AI로 생성한 이미지의 사용 조건은 각 공급자의 약관을 따릅니다. 타인의 사진을 무단으로 사용하거나, 생성 이미지를 오해하게 쓰는 책임은 사용자에게 있습니다.

6. 문의

이 앱은 정적 웹페이지로 배포됩니다. 운영자 연락처는 배포한 저장소의 안내를 따릅니다. 개인정보 관련 요청은 해당 저장소의 이슈로 남겨 주세요.
